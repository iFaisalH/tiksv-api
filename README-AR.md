# VidKeep Vercel - نسخة متعددة المنصات

ارفع الملفات إلى مستودع GitHub الحالي iFaisalH/tiksv-api (استبدل الملفات المتطابقة وأضف الجديدة). سيقوم Vercel بنشرها تلقائياً إن كان الربط موجوداً.

TikTok: المعالج الأصلي دون تغيير. YouTube وInstagram وFacebook وX وPinterest وReddit: yt-dlp في Python Function. نفس نقطة الدخول POST /api/download مع {"input":"URL"}. عداد Cloudflare مستقل ولم يتغير.

**تنبيه**: لم تختبر النسخة على Vercel فعلياً. بعض الروابط تحتاج تسجيل دخول أو تكون محمية، وقد يفشل التنزيل بسبب مهلة Vercel أو حجم الملف أو حجب المنصة. يجب اختبار روابط عامة قبل اعتمادها.
